# ファイルログ出力の削除計画

## 目的

`Batch` / `Auto` 実行時に `oaib.txt` へ書き出していたファイルログ機能を
削除し、実行ディレクトリにログファイルが作られないようにする。

## 実装方針

1. `oaib/Batch.py` から `logdir`、`log()`、`__clear_log()`、および
   すべての `self.log(...)` 呼び出しを削除する。
2. `oaib/Auto.py` のログ呼び出しを削除する。
3. `loglevel` は進捗バー（tqdm）の表示制御だけに残す。
   `0` で非表示、`1` または `2` で表示。ファイルログの詳細度の違いはなくす。
4. ログ専用だった `datetime` の import と、ログのためだけに取っていた
   `model` 変数を削除する。
5. テストの `batch.log()` 呼び出しを削除し、実行後に `oaib.txt` が
   作られないことを確認する。
6. README（`.md` / `.ipynb`）の `oaib.txt` に関する記述を削除し、
   `.gitignore` の `oaib.txt` 行を削除する。

## 確認事項

- 進捗バーと `Run took ...s` の標準出力は残す。
- `loglevel=0` による進捗バー抑制は既存テストが使うため維持する。
- このリポジトリは GitHub Issues が無効のため、Issue は作成できない。
